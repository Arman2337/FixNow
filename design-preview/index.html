4 · Motion & animation — the full playbook

Every animation below is live — click, drag, toggle them. They use only your existing app_motion.dart tokens (150 / 200 / 300 / 340ms, plus the 1.6s ambient pulse, 1.2s shimmer and 60ms stagger step), and each one maps to a primitive your code already has or a one-line addition.

Tokens app_motion.dart · primitives fix_motion.dart · already implemented: fix_button.dart, fix_bottom_navigation.dart, fix_eta_ring.dart, fix_slide_to_confirm.dart, fix_accept_celebration.dart
1 · Motion answers a question. Feedback ("did it register?"), orientation ("where did that go?"), progress ("how long?"), delight ("nice!"). If it answers none, it doesn't ship.
2 · Token durations only. 150ms touch feedback · 200ms state change · 300ms emphasized moment · 340ms screens & sheets. Nothing arbitrary.
3 · Motion never delays an action. Buttons respond instantly; animation rides along. No animation gates a tap.
4· Honest movement. Map markers glide only between real GPS updates — stale coordinates are stamped, never animated as live.
5 · Reduced motion = first class. MediaQuery.disableAnimations skips every non-essential animation, keeping fades/state changes. Try the toggle.

Font · root cause

1Bundle Inter, kill the runtime fetch

Add Inter-Regular/Medium/SemiBold.ttf to mobile/assets/fonts/, declare them in pubspec.yaml, and rewrite app_typography.dart to plain TextStyle(fontFamily: 'Inter'). Text becomes instantly consistent — no Roboto first paint, no mid-session swap, no network dependency.

app_typography.dart · pubspec.yaml · assets/fonts/
Bug · theme

2Fix the fake dark theme

AppTheme.dark only flips a brightness flag and keeps the light palette, so themeMode: dark renders the light theme by accident. Collapse to one honest light theme (AppTheme.light) and point the app + tests at it.

app_theme.dart · app.dart · mobile/test/*
Cleanup

3Remove the google_fonts dependency

Once fonts are bundled, drop google_fonts from pubspec.yaml — one less runtime dependency, smaller app, no font fetch on cold start.
