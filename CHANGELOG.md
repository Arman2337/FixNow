# Changelog

All notable changes to FixNow are documented in this file.

## [0.1.0.0] - 2026-08-11

### Added

- Let providers manage service profiles, skills, coverage radius, weekly schedules, exceptions, and temporary online or busy status.
- Add private provider-document upload, malware scanning, access, deletion, retention, and audit boundaries for local development.
- Add an auditable provider verification workflow with reviewer assignment, explicit decisions, concurrency protection, and verified-provider activation.
- Add shared provider contracts, database migrations, focused tests, and local private-storage documentation.

### Changed

- Align provider and service-category endpoints with centralized authorization policies and validated request contracts.
