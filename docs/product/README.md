# Product documentation

This directory contains the current product requirements and shared domain language for FixNow. It describes intended behavior and constraints; it is not evidence that a feature exists.

- [Product requirements](requirements.md)
- [Domain glossary](glossary.md)

Open product decisions are recorded in the requirements document. Hard-to-reverse technical decisions belong in [`../architecture/decisions/`](../architecture/decisions/) after the relevant product requirement is agreed.
